# BitCraft

**craft.bitpulse.dev**  
*A playground and forge for low-level computing enthusiasts, learners, and open-source tinkerers.*

---

## 🚀 What is BitCraft?

**BitCraft** is a knowledge-sharing platform focused on:

- 🧠 **Low-Level Programming** (Rust, C, Assembly)
- 🛠️ **Embedded Systems & OS Dev**
- 🔍 **Reverse Engineering & Debugging**
- 🎓 **Hands-on Tutorials & Guides**
- 🧰 **Showcases of Open Source Hardware & Software Projects**

Whether you're building a bootloader, tinkering with microcontrollers, or understanding the internals of an OS — BitCraft is your go-to forge.

---

## 📚 What's Inside This Repository?

This repo serves as the **home for BitCraft’s core source and content**:

- `docs/` – Markdown-based tutorials & guides
- `src/` – Source code for demos, simulations, and educational projects
- `tools/` – Utility scripts or helper crates
- `public/` – Assets (logos, diagrams, visual aids)
